# Política de Segurança

## Versões suportadas

Enquanto o projeto não possuir uma versão publicada, correções de segurança são
aplicadas apenas à branch `main`. Após a primeira publicação, somente a versão
mais recente receberá correções.

## Relatando uma vulnerabilidade

Não abra uma issue pública para vulnerabilidades ou suspeitas de exposição de
credenciais.

Use o botão **Report a vulnerability** na aba **Security** do repositório ou
acesse o [formulário privado de
reporte](https://github.com/Diafania-Claritas/CongregaPlenum/security/advisories/new).

Inclua, quando possível:

- descrição e impacto esperado;
- passos mínimos para reprodução;
- versões ou commits afetados;
- prova de conceito sem dados sensíveis;
- sugestão de correção, se houver.

O mantenedor confirmará o recebimento assim que possível, investigará o relato e
coordenará a divulgação depois que uma correção estiver disponível. Evite
divulgação pública antes dessa coordenação.
