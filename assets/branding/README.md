# Identidade visual da Diafania Claritas

A marca combina um croqui do Congresso Nacional com um olho voltado para o
edifício, representando transparência, observação e vigilância cívica.

## Arquivos principais

- `diafania-claritas-logo.svg`: assinatura horizontal para fundos claros.
- `diafania-claritas-logo-inverse.svg`: assinatura horizontal para fundos escuros.
- `diafania-claritas-avatar.svg`: avatar vetorial para fundos claros.
- `diafania-claritas-avatar-inverse.svg`: avatar vetorial para fundos escuros.
- `diafania-claritas-avatar-512.png`: avatar pronto para a organização no GitHub.
- `diafania-claritas-favicon-64.png`: ícone para interfaces em alta densidade.
- `diafania-claritas-favicon-32.png`: favicon compacto.
- `diafania-claritas-social-preview.png`: imagem social 1280×640 para o GitHub.

## Cores

- Azul-marinho: `#071e52`
- Marfim: `#f7f4ed`

Prefira as versões SVG. Os PNGs existem para plataformas que não aceitam
vetores. Preserve a proporção, a área de respiro e a direção do olhar.
