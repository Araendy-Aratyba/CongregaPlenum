# Identidade visual da Diafania Claritas

A marca combina um croqui do Congresso Nacional com um olho voltado para o
edifício, representando transparência, observação e vigilância cívica. O
arquivo canônico da identidade é `diafania-claritas-avatar-inverse.svg`.

## Arquivos principais

- `diafania-claritas-avatar-inverse.svg`: marca padrão, com fundo azul-marinho.
- `diafania-claritas-avatar-512.png`: avatar pronto para a organização no GitHub.
- `diafania-claritas-favicon-64.png`: ícone para interfaces em alta densidade.
- `diafania-claritas-favicon-32.png`: favicon compacto.
- `diafania-claritas-social-preview.png`: imagem social 1280×640 para o GitHub.

As assinaturas horizontais permanecem somente para o README do CongregaPlenum,
onde a apresentação atual foi preservada por decisão de projeto.

## Cores

- Azul-marinho: `#071e52`
- Marfim: `#f7f4ed`

Prefira o SVG canônico. Os PNGs existem para plataformas que não aceitam
vetores. Preserve a proporção, a área de respiro, as cores e a direção do olhar.
